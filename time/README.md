# Time — سامانه مدیریت نوبت و مشتریان

`Time` ماژول مدیریت زمان و ارتباط با مشتری در پروژه `Assistant` است. این نسخه بر اساس جریان‌های ویدیوی مرجع، از صفر و با کد مستقل پیاده‌سازی شده و برای استفاده روی موبایل، تبلت و دسکتاپ واکنش‌گرا است.

## فناوری‌ها

- زبان اصلی: **TypeScript**
- رابط کاربری: **React 19 + Next.js 16 (Vinext)**
- استایل: **CSS واکنش‌گرا با چیدمان RTL**
- بک‌اند: **Route Handlerهای Next.js**
- دیتابیس: **Cloudflare D1 (SQLite) + Drizzle ORM**
- اجرا: **Cloudflare Workers / OpenAI Sites**

## قابلیت‌های پیاده‌سازی‌شده

- داشبورد مدیریتی، آمار نوبت، مشتری، درآمد و رضایت
- تقویم هفتگی و ماهانه، ساعت‌های آزاد و ثبت نوبت
- وضعیت نوبت: تأییدشده، منتظر تأیید، انجام‌شده و لغوشده
- پرونده مشتری شامل موبایل، شغل، تولد، گروه، نحوه آشنایی، یادداشت، مراجعات و خرید کل
- جستجو و گروه‌بندی مشتریان VIP، مهم، معمولی و کارکنان
- مدیریت پرسنل، خدمت، مدت، تعرفه و رنگ تقویم
- پیام گروهی و تاریخچه پیام‌ها
- اتوماسیون یادآوری نوبت، تبریک تولد، بازگشت مشتری و رضایت‌سنجی
- گزارش درآمد، نوبت، گروه مشتری، خدمات پرفروش و بازخوردها
- ابزارهای رزرو آنلاین، قرعه‌کشی، شماره اختصاصی و پشتیبانی
- پروفایل، تنظیمات حساب، پیام شبانه و ناحیه زمانی
- داده نمونه اولیه برای مشاهده سریع محصول

## ساختار مهم پروژه

```text
app/
  page.tsx                 ورودی برنامه
  time-client.tsx          رابط و منطق تعاملی پنل
  globals.css              طراحی کامل و واکنش‌گرا
  api/                     APIهای مشتری، نوبت، پیام و تنظیمات
db/
  schema.ts                مدل‌های دیتابیس
drizzle/                   مهاجرت‌های SQL
lib/
  types.ts                 تایپ‌های مشترک
  server-data.ts           دسترسی و عملیات دیتابیس
  seed.ts                  داده نمونه اولیه
```

## اجرای محلی

پیش‌نیاز: Node.js نسخه `22.13` یا بالاتر.

```bash
npm ci
npm run dev
```

برای ساخت نسخه نهایی:

```bash
npm run build
```

پس از تغییر `db/schema.ts`، مهاجرت جدید را تولید کنید:

```bash
npm run db:generate
```

## نکات توسعه نسخه‌های بعدی

1. اطلاعات واقعی مشتریان فقط از APIها عبور می‌کند و در D1 ذخیره می‌شود.
2. کلید یا رمز محرمانه نباید داخل کد یا Git ثبت شود.
3. برای اتصال سرویس پیامک واقعی، تابع ارسال Provider را به `app/api/messages/route.ts` اضافه کنید؛ در نسخه فعلی پیام در صف ثبت می‌شود.
4. برای چندکسب‌وکاری کردن سامانه، ستون `business_id` را به جدول‌ها و احراز هویت مالک را به APIها اضافه کنید.
5. تاریخ‌های ذخیره‌شده ISO هستند و فقط در رابط به تقویم شمسی نمایش داده می‌شوند؛ این تصمیم گزارش‌گیری و جابه‌جایی بین سرورها را ساده‌تر می‌کند.

## امنیت و حریم خصوصی

نسخه نمایشی شامل داده ساختگی است. قبل از ورود داده واقعی، سیاست دسترسی، احراز هویت کاربران، سطح دسترسی پرسنل و نسخه پشتیبان دیتابیس باید برای محیط نهایی تنظیم شوند.
