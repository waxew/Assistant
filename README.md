# Assistant

مخزن یکپارچه ابزارها و ربات‌های پروژه Assistant.

## ماژول‌ها

| پوشه | کاربرد | فناوری اصلی |
| --- | --- | --- |
| [`telegram/`](telegram/) | ربات فروشگاه‌ساز چندکاربره تلگرام | Python، aiogram، PostgreSQL |
| [`time/`](time/) | سیستم نوبت‌دهی، پرونده مشتری و مدیریت پرسنل | TypeScript، React، Next.js، D1 |

هر ماژول مستقل است و راهنمای نصب، تنظیمات و توسعه نسخه‌های بعدی داخل فایل `README.md` همان پوشه قرار دارد.

## اصول نگهداری

- فایل‌های `.env`، توکن‌ها و کلیدهای محرمانه داخل Git ثبت نشوند.
- تغییرات دیتابیس هر ماژول با migration نسخه‌بندی شوند.
- قبل از انتشار، آزمون‌ها و دستور build همان ماژول اجرا شوند.
- نسخه‌های بعدی به‌صورت پوشه مستقل در همین مخزن اضافه شوند.
