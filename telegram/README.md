# ربات فروشگاه‌ساز چندکاربره تلگرام

نسخه ۱٫۰ یک بازسازی عملکردی مستقل از سامانهٔ نمایش‌داده‌شده در ویدئو است. یک «ربات مادر» توکن ساخته‌شده در BotFather را می‌گیرد، آن را رمزنگاری می‌کند و برای هر کاربر یک ربات فروشگاه جدا با دیتای کاملاً تفکیک‌شده اجرا می‌کند.

## زبان و فناوری

- زبان: **Python 3.12**
- Telegram framework: **aiogram 3** (کاملاً async)
- دیتابیس: **PostgreSQL** برای سرور و **SQLite** برای توسعه محلی
- ORM و migration: **SQLAlchemy 2 + Alembic**
- پرداخت: کارت‌به‌کارت با تأیید مدیر و زرین‌پال v4 با callback و verify
- اجرا: Docker Compose یا اجرای مستقیم Python

## امکانات

### ربات مادر

- ساخت ربات «برای خودم» با دوره آزمایشی رایگان
- ساخت ربات «برای مشتری» با کسر هزینه و اشتراک فعال
- اعتبارسنجی توکن با Telegram، حذف best-effort پیام حاوی توکن و ذخیره رمزنگاری‌شده
- ربات‌های من، وضعیت اشتراک، تمدید، کیف پول، رسید کارت‌به‌کارت
- لینک معرفی، پاداش اولین شارژ زیرمجموعه و پشتیبانی

### ربات فروشگاه هر کاربر

- دسته‌بندی، فهرست و جستجوی محصول، تصویر و لینک مستقیم محصول
- چند پلن قیمت برای هر محصول و تغییر گروهی قیمت (درصدی/مبلغی)
- تحویل خودکار متن، تصویر، ویدئو، صوت یا فایل؛ همچنین سفارش دستی
- کیف پول، کارت‌به‌کارت، زرین‌پال، کد تخفیف مبلغی/درصدی
- کد پیگیری سفارش، سوابق، معرفی دوستان و پاداش اولین خرید
- پشتیبانی دوطرفه با Reply مدیر
- پنل مدیر: مالی، دسته‌ها، محصولات، آمار، کاربران، پیام همگانی، تخفیف، تنظیمات عمومی، عضویت اجباری، کانال لاگ/رضایت، ادمین دوم و بکاپ SQL
- Audit log و جداسازی همه رکوردها با `tenant_id`

جزئیات تطبیق قابلیت‌ها در [docs/FEATURES.md](docs/FEATURES.md) آمده است.

## راه‌اندازی سریع با Docker

پیش‌نیازها: Docker و Docker Compose، یک ربات مادر از `@BotFather` و شناسه عددی تلگرام مدیر.

```bash
cp .env.example .env
python scripts/generate_key.py
```

خروجی دستور دوم را در `TOKEN_ENCRYPTION_KEY` قرار دهید. سپس حداقل این موارد را در `.env` تنظیم کنید:

```dotenv
BUILDER_BOT_TOKEN=توکن_ربات_مادر
SUPER_ADMIN_IDS=شناسه_عددی_شما
TOKEN_ENCRYPTION_KEY=کلید_تولیدشده
PUBLIC_BASE_URL=https://دامنه-عمومی-شما.example
```

اکنون اجرا کنید:

```bash
docker compose up -d --build
docker compose logs -f app
```

برای تست سلامت سرویس:

```bash
curl http://localhost:8080/healthz
```

در تلگرام ربات مادر را باز کنید، `/start` را بزنید و «ساخت ربات فروشگاه» را انتخاب کنید. توکن ربات فروشگاهی که با BotFather ساخته‌اید بفرستید؛ بقیه مراحل داخل تلگرام انجام می‌شود.

## اجرای محلی بدون Docker

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env
python scripts/generate_key.py
python -m app.main
```

SQLite به‌صورت پیش‌فرض فایل `data/store_builder.db` را می‌سازد. برای محیط واقعی از PostgreSQL استفاده کنید.

## تنظیم زرین‌پال

1. `PUBLIC_BASE_URL` باید یک دامنه عمومی HTTPS باشد و پورت ۸۰/۴۴۳ را به برنامه برساند.
2. در پنل مدیریت هر فروشگاه، Merchant ID را ثبت و زرین‌پال را فعال کنید.
3. مبلغ در رابط کاربری «تومان» است؛ ماژول درگاه هنگام ارسال به زرین‌پال آن را به ریال تبدیل می‌کند.
4. کیف پول فقط پس از پاسخ `verify` موفق شارژ می‌شود و callback تکراری دوباره موجودی را افزایش نمی‌دهد.

## توسعه نسخه‌های بعدی

- مدل‌ها: `app/models.py`
- منطق ربات مادر: `app/bots/builder.py`
- منوی مشتری: `app/bots/store/customer.py`
- پنل مدیر: `app/bots/store/admin.py`
- منطق تراکنشی فروشگاه: `app/services/store.py`
- اجرای پویا و هم‌زمان ربات‌ها: `app/services/registry.py`

پس از تغییر مدل دیتابیس:

```bash
alembic revision --autogenerate -m "شرح تغییر"
alembic upgrade head
```

راهنمای انتشار امن نسخه بعدی در [docs/UPGRADING.md](docs/UPGRADING.md) است.

## نکات امنیتی مهم

- فایل `.env` و کلید رمزنگاری را هرگز در Git یا چت منتشر نکنید.
- از `TOKEN_ENCRYPTION_KEY` بکاپ امن بگیرید؛ بدون آن توکن‌های ذخیره‌شده قابل بازیابی نیستند.
- اگر توکنی افشا شد، در BotFather آن را revoke کنید و ربات را دوباره ثبت کنید.
- PostgreSQL، دامنه HTTPS، مانیتورینگ و بکاپ خارج از سرور برای محیط production توصیه می‌شود.
- این پروژه فقط از Bot API رسمی استفاده می‌کند و به حساب شخصی کاربر یا رمز عبور تلگرام دسترسی ندارد.
