# نقشه قابلیت‌های نسخه ۱٫۰

این فهرست از مشاهده کامل ویدئوی مرجع تهیه شده و معادل عملکردی هر جریان را مشخص می‌کند. پیاده‌سازی «کپی سورس خصوصی» نیست؛ کد از صفر نوشته شده است.

| بخش ویدئو | پیاده‌سازی این پروژه |
|---|---|
| ساخت ربات از توکن BotFather | اعتبارسنجی `getMe`، رمزنگاری Fernet، fingerprint و اجرای فوری tenant |
| برای خودم / برای مشتری | trial رایگان یا کسر هزینه و اشتراک فعال ۳۰ روزه |
| ربات‌های من و تمدید | وضعیت trial/active/expired، روز باقی‌مانده و تمدید از کیف پول |
| حساب ربات‌ساز | موجودی، لینک معرفی، تراکنش‌ها، رسید شارژ و پاداش معرفی |
| محصولات و جستجو | دسته‌بندی، جستجوی فارسی/انگلیسی، تصویر، توضیحات و deep link |
| پلن‌های محصول | چند پلن، افزودن/ویرایش/حذف و تغییر گروهی قیمت |
| تحویل خودکار | ذخیره و ارسال ترتیبی متن/عکس/ویدئو/صوت/فایل تا ۵۰ آیتم |
| تحویل دستی | دریافت اطلاعات لازم، اعلان مدیر و ثبت تحویل |
| پرداخت و کیف پول | کارت‌به‌کارت با رسید، زرین‌پال request/verify و گردش حساب |
| تخفیف | مبلغ ثابت یا درصد، سقف استفاده و غیرفعال‌سازی |
| پیگیری سفارش | کد ۱۰ رقمی، وضعیت پردازش/تحویل و تاریخچه کاربر |
| پشتیبانی | relay پیام و فایل و پاسخ مدیر با Reply |
| آمار | کل و ماهانه کاربران، خریداران، فروش و شارژ کیف پول |
| مدیریت کاربران | جستجو با Telegram ID، تغییر موجودی و block/unblock |
| مدیریت پیام‌ها | مستقیم، ارسال همگانی copy و forward |
| مدیریت عمومی | متن/تصویر شروع، ادمین دوم، عضویت اجباری، کانال رضایت/لاگ و پشتیبانی |
| بکاپ | فایل SQL مخصوص همان فروشگاه بدون توکن ربات |

## محدودیت‌های آگاهانه نسخه ۱٫۰

- اجرای tenantها در نسخه حاضر با long polling است. برای چند صد/هزار ربات، registry را بین workerها shard یا به webhook تبدیل کنید.
- FSM موقت در حافظه است؛ تراکنش‌ها و داده‌های تجاری پایدارند اما ویزارد نیمه‌تمام بعد از restart از ابتدا آغاز می‌شود. برای HA از Redis storage استفاده کنید.
- Telegram محدودیت ارسال پیام دارد؛ broadcast به‌آرامی ارسال می‌شود. برای حجم بالا آن را به صف کار جدا منتقل کنید.
- نام دکمه‌ها و پیام‌ها به‌صورت متمرکز در فایل‌های bot قابل ویرایش‌اند و ممکن است ظاهر کلاینت‌های مختلف تلگرام اندکی متفاوت باشد.
